# Web Content Accessibility Guidelines (WCAG) Quick Reference

WCAG 2.1 is organized around four core principles: Perceivable, Operable, Understandable, and Robust (POUR).

## 1. Perceivable
- Text alternatives for non-text content (`alt` attributes).
- Captions and transcripts for multimedia.
- Content can be presented in different ways (e.g. simpler layout) without losing information.
- Sufficient color contrast (minimum 4.5:1 for normal text, 3:1 for large text; 7:1 for AAA).

## 2. Operable
- All functionality available from a keyboard.
- Users have enough time to read and use content.
- Content does not cause seizures or physical reactions (no rapid flashing).
- Clear navigation: page titles, headings, visible focus indicators, skip links.

## 3. Understandable
- Text is readable and understandable; clear terminology.
- Web pages appear and operate in predictable ways.
- Input assistance: help users avoid and correct errors.

## 4. Robust
- Maximize compatibility with current and future user tools, including assistive technologies.
- Valid markup, correct ARIA roles, states, and properties.
