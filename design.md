Saarthi visual direction
1. Overall theme
Light mode only. No dark mode.
The entire product should have a clean, bright appearance:
- Very light gray page background
- White content surfaces
- One consistent purple brand color
- Dark charcoal text
- Very subtle borders/shadows
- No gradients
- No glassmorphism
- No neon
- No excessive colors
The feeling should be:
Professional job platform + modern SaaS + accessibility-first.

Not an "AI futuristic" interface.
2. One main purple
I agree with you on this:
The same purple should be used throughout the product.

So we shouldn't have one purple for buttons, another purple for cards, another purple for navigation, etc.
Let's establish one main Saarthi purple:
Primary: #40189D
Use this consistently for:
- Primary buttons
- Active navigation
- Job-card primary CTA
- Selected states
- Important links
- Main brand elements
- Extension branding
- Important icons
Then we can have one very light tint of the same purple for backgrounds:
Light Purple: #F1EBFF
That's not a second brand color. It's simply the light version of the same purple.
3. Background
The page itself should not be pure white.
Use:
Background: #F5F5F6
Then:
Cards / surfaces: #FFFFFF
So visually:
LIGHT GRAY BACKGROUND

      ┌─────────────────────────┐
      │       WHITE CARD        │
      │                         │
      │                         │
      └─────────────────────────┘

This gives us the same clean separation visible in the reference.
4. Cards
This is important from your point:
Job cards should have the same visual language as the rest of the cards.

Don't create a special "job card design."
Everything should belong to the same card system.
Standard Saarthi card
- White background
- 1px subtle border
- 12–14px radius
- Very subtle shadow
- Same padding
- Same heading hierarchy
- Same hover behavior
Then:
Dashboard Card = Job Card = Application Card = Profile Card
The content changes, but the visual component language stays the same.
5. Buttons
Same thing.
There should be one primary button style throughout Saarthi.
Primary
Background: #40189D
Text: #FFFFFF
Radius: 10–12px

Example:
┌──────────────────────────────┐
│       Apply with Saarthi     │
└──────────────────────────────┘

Every important CTA should look like this.
Examples:
- Get Started
- Continue
- Save Changes
- Find Jobs
- Apply with Saarthi
- Confirm & Submit
- Upload Resume
Same purple.
Same shape.
Same typography.
6. Secondary buttons
Secondary buttons should not introduce another color.
Use white:
Background: #FFFFFF
Border: #E2E2E5
Text: #333333

Example:
┌──────────────────┐
│    View Job      │
└──────────────────┘

So the hierarchy becomes:
Purple = primary action
White = secondary action
That's it.
7. Pills / Tags
Here we can use the light purple tint:
Background: #F1EBFF
Text: #40189D

Example:
[ Remote ] [ Full-time ] [ React ]

Selected:
[ ✓ Remote ]

can become:
background: #40189D
text: white

This is similar to the reference's skill/filter pills.

Exactly the same card.
┌────────────────────────────────────────────┐

│                                            │
│  LinkedIn · Applied Oct 3                  │
│                                            │
│  [ Applied ]                               │
│                                            │
│                          [ View Details ]  │
│                                            │
└────────────────────────────────────────────┘

Same:
- White
- Same radius
- Same border
- Same spacing
- Same typography
The status pill can use the light purple system for the default application state.
For genuinely semantic states like rejected/error, we can introduce restrained semantic colors only when necessary.
10. Typography
The reference's typography is not huge.
I would use:
Font
Inter
Main heading
32–36px / 700
Section heading
22–24px / 600
Card title
17–18px / 600
Body
14–16px / 400
Supporting text
13–14px / 400
This gives us the compact professional feel from your reference.
Don't make the dashboard look like a landing page with 60px headings everywhere.
11. Text colors
Keep it simple.
Primary
#222222
Secondary
#6F6F73
Muted
#99999D
So the visual hierarchy is created through weight + size + contrast, not through lots of colors.
12. Navigation
Since you specifically like the visual character of that reference, I think we should use the purple navigation treatment.
But we don't have to copy its exact layout.
Something like:
┌──────────────────┬────────────────────────────────────┐
│                  │                                    │
│     SAARTHI      │  Dashboard                         │
│                  │                                    │
│  Overview        │  Welcome back                      │
│  Jobs            │                                    │
│  Applications    │  [ cards ... ]                     │
│  Profile         │                                    │
│  Extension       │                                    │
│  Settings        │                                    │
│                  │                                    │
└──────────────────┴────────────────────────────────────┘

Purple navigation:
#40189D
White navigation text.
Active navigation item:
White/light surface + purple text.
That gives us the strongest visual identity without making the entire application purple.
13. Shadows
Very subtle.
We don't want floating cards everywhere.
Something like:
0 2px 8px rgba(0,0,0,0.05)

And cards should primarily be separated through:
light-gray background + white surface + subtle border.
14. What we are explicitly NOT doing
Let's lock this because it will prevent the coding AI from going crazy:
❌ No dark mode
❌ No gradients
❌ No purple-to-blue gradients
❌ No glassmorphism
❌ No neon
❌ No multiple primary colors
❌ No colorful dashboard statistic cards
❌ No different button colors for different sections
❌ No huge rounded 30px cards
❌ No excessive shadows
❌ No giant typography
❌ No random illustrations everywhere
❌ No "AI futuristic" visual style
15. The Saarthi visual formula
This is what I want the final design.md to communicate:
              SAARTHI UI

        ┌─────────────────────┐
        │                     │
        │   PURPLE #40189D    │
        │                     │
        └─────────────────────┘

               +

       WHITE CONTENT CARDS

               +

       LIGHT GRAY BACKGROUND

               +

       DARK CHARCOAL TEXT

               +

       LIGHT PURPLE PILLS

               +

       CONSISTENT BUTTONS

One brand color.
One light tint.
Neutral UI everywhere else.
That will make the product look much more professional and much closer to the visual quality you're pointing at.
And yes — I would keep the exact same card language for Job Cards, Application Cards, Dashboard Cards, Profile Cards and Extension-related panels. The product should feel like one coherent design system, not five different UI styles.
